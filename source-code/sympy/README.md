# Sympy
Some simple sympy examples.

## What is it?
1. `pendulum_sympy_intro.ipynb`: introduction to symbolic expressions,
   functions, differentiation, integration, limits, series, and numerical
   callables using an ideal pendulum as a running example.
1. `equation_solving_with_sympy.ipynb`: tutorial on scalar equations, linear
   and nonlinear systems, solution branches, admissibility, and residual
   validation using source localization from range measurements.
1. `sympy.ipynb`: Jupyter notebook with some simple sympy examples.
1. `triple_six_puzzle.ipynb`: Jupyter notebook that illustrates how to
    use computer algebra to solve a numerical puzzle.
1. `factorial_digits.ipynb`: Jupyter notebook using sympy to compute the
    number of digits of the factorial of a number.
1. `pendulums.ipynb`: Jupyter notebook on using the Euler-Lagrange equations to
   derive the equation for the motion of pendulums.
1. `triangles.ipynb`: Jupyter notebook illustrating the probability of
   constructing triangles from cutting a rope.
1. `plotting`: illustration of using alternative backends for plots in sympy.
1. `img`: images for notebooks.
