# Exercises

This repository contains three exercise sheets with different levels of scope and difficulty. Start with the shorter sheets for tutorial sessions or quick practice, and use the challenging sheet for longer assignments or mini-projects.

## Exercise Sheets

* [`exercises_very_short.md`](exercises_very_short.md): 5-10 minute warm-up exercises covering small NumPy, SciPy, and SymPy tasks. These start from scratch and focus on one or two functions at a time.
* [`exercises_short.md`](exercises_short.md): approximately 30-minute exercises based on the notebooks and example code in this repository. These are suitable for tutorials, short labs, or preparatory work.
* [`exercises_challenging.md`](exercises_challenging.md): longer, more sophisticated assignments and mini-projects for advanced practice with scientific Python.
